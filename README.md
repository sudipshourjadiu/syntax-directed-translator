# 🧠 Syntax-Directed Translator for Arithmetic Expressions (Flex + Bison)

This project is a **syntax-directed translator** that takes **simple arithmetic expressions** (like `2 + 3 * 4`) and outputs the corresponding **postfix notation** (Reverse Polish Notation: `2 3 4 * +`). It is implemented in **C using Flex** (for lexical analysis) and **Bison** (for parsing and syntax-directed translation).

---

## 📋 Features

- Basic arithmetic operations: `+`, `-`, `*`, `/`
- Parentheses for grouping
- Unary minus (e.g., `-5`)
- Outputs **postfix notation**
- Simple and easy to extend

---

## 📦 Requirements

You need the following tools installed on your Linux system:

- `gcc` (C compiler)
- `flex` (fast lexical analyzer)
- `bison` (parser generator)

---

## 🛠️ Installation (Linux)

### ✅ Step 1: Install Dependencies

On Debian/Ubuntu:
```bash
sudo apt update
sudo apt install flex bison gcc
```

On Arch:
```bash
sudo pacman -S flex bison gcc
```

On Fedora:
```bash
sudo dnf install flex bison gcc
```

---

## 🔧 Build Instructions

Clone the project (or download the files), then run:

```bash
bison -d parser.y         # Generates parser.tab.c and parser.tab.h
flex lexer.l              # Generates lex.yy.c
gcc parser.tab.c lex.yy.c -o translator
```

> ⚠️ If you see a `_yywrap` undefined error, make sure this is at the bottom of `lexer.l`:

```c
int yywrap() { return 1; }
```

---

## 🚀 Usage

Run the program:

```bash
./translator
```

Then input an arithmetic expression like:

```
(2 + 3) * 4
```

**Output:**
```
2 3 + 4 *
```

---

## 📁 File Structure

```
.
├── lexer.l        # Flex lexer specification
├── parser.y       # Bison grammar with semantic actions
├── parser.tab.c   # Generated by Bison
├── parser.tab.h   # Token definitions from Bison
├── lex.yy.c       # Generated by Flex
└── translator     # Final compiled binary
```

## 🔄 Example Translations

| Input             | Postfix Output     |
|------------------|--------------------|
| `2 + 3 * 4`       | `2 3 4 * +`        |
| `-5 + (8 / 2)`    | `5 ~ 8 2 / +`      |
| `(1 + 2) * (3 - 4)` | `1 2 + 3 4 - *`  |

---

## 🧠 How It Works

- **Flex (`lexer.l`)** tokenizes input into numbers, operators, and parentheses.
- **Bison (`parser.y`)** applies grammar rules and prints postfix notation during parsing using actions.
- **Syntax-directed translation** is used to emit output as the grammar is parsed.
